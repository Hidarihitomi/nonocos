# nocos - ColorOS 模块合集

基于 `libxposed API 102` 的 ColorOS 模块合集，包名 `com.xixi.nocos`。四个模块各自独立配置，保存后重新打开对应应用生效。

| 模块 | 作用应用 | 功能 |
| --- | --- | --- |
| 应用增强服务 | `com.oplus.cosa` | 修改应用增强服务读取的机型代号。 |
| 截屏 | `com.oplus.screenshot` | 三指区域截屏松手后直接进入框选。 |
| 桌面 | `com.android.launcher` | 长按图标时，把「更多功能」里的项目直接展开到一级菜单；隐藏最近任务底部的「清理」按键。 |
| 主题商店 | `com.heytap.themestore` | VIP Hook |
